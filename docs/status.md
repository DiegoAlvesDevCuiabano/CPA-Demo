# CPA-Demo — status

> Atualizado em 09/10/2026. A frente principal de trabalho é o Delibera.

O CPA-Demo é uma demonstração estática de uma plataforma de Comissão Própria de Avaliação. As 27 páginas HTML foram abertas em navegador automatizado e responderam HTTP 200 com título. A demonstração está em https://diegoalvesdevcuiabano.github.io/CPA-Demo/landing.html.

O login, cadastro, questionários, relatórios e assinatura são telas de protótipo; este repositório não contém backend, autenticação real, persistência ou cobrança. Os preços exibidos são parte do protótipo e não constituem oferta operacional validada.

**Situação:** apresentação navegável; desenvolvimento comercial e técnico aguardam a conclusão da homologação prioritária do Delibera. Antes de vender, definir MVP funcional, tratamento dos dados de avaliação, autenticação, cobrança e operação.
