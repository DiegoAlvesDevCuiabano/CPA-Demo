# CPA Demo

[**Abrir demonstração navegável**](https://diegoalvesdevcuiabano.github.io/CPA-Demo/landing.html)

Protótipo de interface para uma plataforma de Comissão Própria de Avaliação. As páginas mostram uma proposta de fluxo para configuração de ciclos, questionários, respostas, acompanhamento e relatórios.

> **Estado:** demonstração estática. Login, cadastro, questionários, relatórios, assinatura e preços exibidos nas telas são parte do protótipo; este repositório não contém backend, autenticação real, persistência ou cobrança. [Status atualizado](docs/status.md)

## Explore o fluxo

1. Comece pela [apresentação](landing.html).
2. Veja o [painel CPA](dashboard-cpa.html) e os [ciclos](ciclos.html).
3. Explore o [editor de questionários](questionario-editor.html), a [resposta](responder.html) e o [relatório](relatorio.html).

As telas são arquivos HTML independentes. Para leitura local, clone o repositório e abra `landing.html` no navegador. A versão publicada no GitHub Pages facilita a navegação sem instalação.

## Escopo técnico

- Interface estática em HTML, CSS e JavaScript.
- Sem API ou banco de dados neste repositório.
- Sem envio real de respostas ou criação de contas.

Antes de transformar a demonstração em produto, faltam definição do MVP, autenticação, tratamento dos dados de avaliação, operação e validação da proposta comercial. Este README descreve a interface existente, não uma oferta de serviço ativa.
